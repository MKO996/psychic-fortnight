# Changelog

## 1.0.0 (28 Nov 2026)

First full version of LEFT.

**Money planning**
- One deterministic plan in integer pence: Safe to spend today, left until payday, bills, essentials, debts, goals.
- Talk or type (local parser, "twenty-five pounds"), Check what I heard, affordability preview.
- Make my plan wizard, Help me split it, new pay period, undo and correct.

**Game**
- Character card with coin avatar, levels, XP, streaks, outfits.
- Daily quest cards, trophies, goal stars. XP rewards habits, never spending.
- Coin check-in reminders (day 1, 3, 7) with a demo and a mock email.

**Insights and people**
- Insights for Today, This week and This month: Coming up, Worth changing, Keep doing.
- About you (all taps), Quick add, Upcoming payments.
- A/B test of stat names (`?v=a`, `?v=b`).

**Look**
- Clean "Play" style: cool grey, violet accent, bento tiles, light and dark themes.

**New in 1.0**
- Add to Home Screen on iPhone and Android, with a LEFT coin icon.
- Works offline after the first visit (service worker caches only the app's own files).
- Version shown in Settings.
- Upgraded to React 19, Vite 8, Vitest 5 and TypeScript 7. The build is about 8× faster, with 0 known vulnerabilities.
